## F1 在配置里管理服务器

- 目标：增删主机不用改代码，服务器列表只有一份。
- 做法：
  - Host 端声明插件配置，服务器列表从配置读取。
  - Host 端提供一个接口把列表下发给浏览器端，浏览器端不再写死 `SERVERS`。
  - 在插件设置页提供表单（平台的 `plugins.row.config` 位置）。
- 顺带解决 `improvements.md` 的 O1。

## F2 插件自己管理隧道和代理

- 目标：打开桌面应用就能用，不依赖仓库外的代理脚本和两个 LaunchAgent。
- 做法：
  - 把 `dsh-remote-proxy.mjs` 的逻辑收进插件的 Host 端。
  - 每台主机一条 SSH 隧道和一个本地代理端口，随插件启动和退出。
  - 代理校验 `Host`、`Origin` 和 `Sec-Fetch-Site`。
- 顺带解决 `bugs.md` 的 B4 和 `improvements.md` 的 O2。

## F3 连接状态

- 目标：一眼看出远端是否可用，不可用时知道原因。
- 做法：
  - Host 端记录每台主机的状态：连接中、在线、离线，以及最近一次错误。
  - 顶栏显示状态；离线时在 iframe 的位置显示原因和重试按钮，而不是空白页。

## F4 更完整的同步

- 预览：先展示将要推送的内容（脚本已有 `--dry-run`）。
- 可选“只同步不重启”。
- 重启前确认，因为重启会中断远端正在跑的会话。
- 实时日志，替代现在最长 5 分钟的无进度等待。
- 完成后自动刷新 iframe。

## F5 小功能

- 在外部浏览器打开当前主机。
- 记住上次打开的主机。
- 切换主机的快捷键。
